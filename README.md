# ATM Simulation Project

This is a simple ATM simulation app built using **Python** and **Streamlit**.  
It allows users to:
- Enter account number and PIN
- Check balance
- Deposit money
- Withdraw money
- View transaction history

## 🚀 Features
- Secure PIN input (hidden password field)
- Interactive Streamlit UI
- Transaction history tracking
- Simple and easy-to-use interface

## 🛠️ Requirements
- Python 3.10+
- Streamlit
